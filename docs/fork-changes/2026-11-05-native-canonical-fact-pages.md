# Native canonical fact query pages

Canonical reducer output was retained project-wide solely for organization and report consumers. The unused project conflict DTO list is removed; ConflictDetector still computes conflicts inside the complete bounded partition and applies exact statuses.

QualifiedFactIndex now indexes canonical semantic identity, canonical subject and evidence addresses alongside existing native references. `canonical_page` selects identities in native storage using bounded cursor, subject and evidence scopes, then invokes the existing complete-partition ConflictDetector owner only for selected partitions. It returns exact canonical DTOs including all support observations, evidence, qualifiers and conflict statuses. Oversized semantic groups/items fail explicitly. No DTO JSON, copied text or independent business semantics are persisted. `topology_page` reads only the staged canonical fact id and endpoint projection.

The query contract supports pending current generation only. Native generation/source-plan/seal fencing remains enforced; cancellation and withdrawal invalidate reads. Page size is at most 128, response bytes use PublicationRecords.MAX_BYTES, scope list at most 128, semantic groups at most 4096 observations and 16 MiB. Selective identity reads remain storage-filtered; no point lookup scans project DTOs. Full topology traversal remains caller-owned and must be consumed incrementally.

Red specification: `/tmp/g4-fact-output-red.log` records missing APIs. `tests/triplet_store/test_qualified_fact_index.py` covers complete partition oracle, cross-page support, conflicting polarity, native filtered hydration, reopened seek pagination, byte/row bounds and withdrawal. Consumer migration is owned by the main builder integration and this capability alone does not close G4.

Report admission additionally uses `stage_reconciled` to attach exact reducer statuses to native reference entries; `family_page` supplies subject/predicate, immutable observation representation support and the required conflict/retraction flag. Family source groups have explicit 4096 source and response byte bounds. `canonical_page` accepts native predicate scopes; `topology_page` includes normalized native predicate type. Family metadata cannot be read before every indexed observation has a reconciled status. Tests verify cursor traversal, all required families, complete source support and explicit source/byte overflow failure.

The report family representation projection is verified against actual builder EvidenceSpan.representation_id values. The extraction binding contains the input representation revision, which differs from the derived evidence representation identity; the index therefore reads the accepted source identity projection's buildRepresentationId with its native integrity validation. The test first reproduced this mismatch and now passes with the native owner correction. Missing identity projections fail explicitly. The shared publication fixture now stages real identity projections.

Measured qualified index write throughput: the same 4096-observation complete conflict fixture took 42.391 seconds to index with one durable mutation per observation. Build now batches the existing native mutation owner by at most 128 observations and 262144 serialized triple bytes. Every observation retains cancellation/generation fencing, native membership/type and accepted identity projection validation; duplicate detection covers both buffered and already committed observations. The final seal follows the final persisted batch only. Interrupted partial batches/generations remain unreadable; retry explicitly replaces the partial index. New regressions cover bounded mutations, cancel/reopen/retry and a generation change while a batch is pending.

With unchanged 4096 records /16 MiB reducer limits, the same local probe indexed in 8.706 seconds (4.87x faster), reconciled in 6.759 seconds, and matched the full ConflictDetector oracle exactly. Parent peak RSS was 146833408 bytes (fresh-process baseline 92520448). 4098 records still fail before emission. These non-model fixture measurements qualify this owner seam only; full ESG performance remains separate acceptance.
