# Native qualified fact projection and builder cutover

The replaced path retained every source assertion/relation DTO until global fact reconciliation, with a project-wide native fact reference dictionary during artifact writing. It now projects one source while its grounded observations exist, persists only derived identifiers, normalized predicate/qualifier scalars and ordered evidence addresses in the existing native extraction owner, then releases source fact DTOs and native reference maps before the next source.

`ExtractionRecords` point-opens accepted Relation addresses and validates operation identity, source binding and membership. The derived `:fact-projection` graph is digest sealed, contains no serialized DTO or quote, enforces field/cardinality/byte bounds and hydrates each exact original source assertion/relation from native accepted values and derived addresses. Accepted extraction facts and their receipt are unchanged. Offline operation cleanup must delete the derived fact graph together with its owning operation; normal reads do not perform migration or fallback.

The builder pages pending native Relations, binds endpoints through unique staged canonical membership and builds the native `QualifiedFactIndex`. The existing `ConflictDetector` remains the only semantic reducer, processing complete qualified partitions. Canonical fact support membership and representative selection are staged during each completed partition. There is no global original DTO lookup or project-wide input assertion/relation collection.

Canonical output DTO lists remain for the current organization/report protocol; this change does not claim to eliminate that residency or prove target ESG capacity. One oversized qualified partition explicitly fails before its result is emitted under the existing group budget; the default budget is a safety limit, not a measured ESG capacity target.
